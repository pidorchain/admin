Админ-панель

Иконка: эмодзи или короткий символ (до 8 знаков). Созданный значок можно выдавать на вкладке «Пользователи».

Сменить ID

Пустое поле = случайный свободный ID. Лаунчер игрока подхватит новый ID при следующей синхронизации (до пары минут). Старый ID освободится.
